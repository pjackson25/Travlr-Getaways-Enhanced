# Travlr Getaways – Enhanced

## CS 499 Computer Science Capstone

This repository contains the enhanced version of my Travlr Getaways full-stack web application. The original project was developed during CS 465 Full Stack Development and was selected as an artifact for my CS 499 Computer Science Capstone ePortfolio.

## Project Overview

Travlr Getaways is a full-stack travel application that allows travel information to be stored, retrieved, and managed through a web-based interface. The application uses a MEAN-stack architecture and separates the customer-facing website, administrative application, API, and database functionality.

The enhanced version demonstrates improvements in software engineering and design, algorithms and data structures, database development, and application security.

## Enhancements

### Software Engineering and Design
The application was enhanced to improve its overall structure, functionality, maintainability, validation, and error handling. The project demonstrates the use of modular application components, RESTful API architecture, and separation of concerns.

### Algorithms and Data Structures
The enhanced application demonstrates improved methods for processing and retrieving trip information. Search, filtering, sorting, and data-handling techniques provide more efficient ways to work with travel records.

### Databases
MongoDB and Mongoose are used to manage trip and user information. Database enhancements focus on validation, querying, data integrity, and integration between the database, API, and application.

### Security
The application incorporates authentication and authorization functionality using JSON Web Tokens (JWT) and Passport. Protected functionality helps prevent unauthorized access to administrative operations.
